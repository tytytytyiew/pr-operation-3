# Практическая работа № 1 (Вариант B)

## 1. Настройка пользователей и прав
Были выполнены команды:
sudo groupadd developers
sudo useradd -m -s /bin/bash -g developers student2
sudo mkdir -p /srv/shared
sudo chown root:developers /srv/shared
sudo chmod 770 /srv/shared
sudo chmod g+s /srv/shared

## 2. Проверка прав доступа
При попытке удалить файл, созданный `student2`, от имени основного пользователя (не входящего в группу `developers`):
`rm: cannot remove '/srv/shared/test.txt': Permission denied`
**Объяснение:** Права `770` (`rwxrwx---`) разрешают чтение, запись и выполнение только владельцу (`root`) и членам группы (`developers`). Остальные пользователи не имеют доступа к каталогу.

## 3. Ответы на контрольные вопросы
* **Чем `su` отличается от `sudo`?** `su` полностью переключает сессию на другого пользователя (требует пароль целевого пользователя, обычно root), а `sudo` выполняет одну команду с повышенными привилегиями, запрашивая пароль текущего пользователя.
* **Почему в Ubuntu по умолчанию заблокирован вход под root?** Для безопасности, предотвращения системных ошибок и аудита через логи `sudo`.
