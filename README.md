## Структура лабораторных и практических работ
Каждая папка содержит полноценный, автономный и исполняемый скрипт на Python, отражающий классические темы курса операционных систем:
* **`pr01/`** — Пользователи, учетные записи, UID/GID, файлы `/etc/passwd` и `/etc/group` (`user_env.py`)
* **`pr02/`** — Индексы файлов (Inode), права доступа `chmod`, структура `stat` (`file_perms.py`)
* **`pr03/`** — Управление процессами, иерархия PID/PPID, системный вызов `fork`/`exec` (`process_control.py`)
* **`pr04/`** — Текстовые потоки, фильтрация журналов и логов ОС (`text_streams.py`)
* **`pr05/`** — Переменные окружения ОС, пространство имен процессов (`env_manager.py`)
* **`pr06/`** — Сетевые интерфейсы, сокеты и диагностика (`network_lab.py`)
* **`pr07/`** — Файловая система, файловые дескрипторы и обход каталогов (`file_system_lab.py`)
* **`pr08/`** — Мониторинг аппаратных ресурсов, ядер CPU и виртуальной файловой системы `/proc` (`hardware_os_lab.py`)
